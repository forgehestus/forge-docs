# Plans and availability

<span class="badge badge-live">Live</span>

Forge is offered in three plans: Team, Business and Enterprise. For prices and current terms, see the pricing page on [forgestus.ai](https://forgestus.ai). The table below shows what is available on each plan.

| Capability | Team | Business | Enterprise |
|---|---|---|---|
| Node, React, Flutter | Yes | Yes | Yes |
| .NET, .NET Framework (Windows runners), Blazor, WPF and WinForms, Windows services, SSDT, Next.js, Angular, Vite, Java, Python | No | Yes | Yes |
| Unity, custom stack onboarding | No | No | Yes |
| Migration, safety net, [Parity Proof](../modernization/parity-proof.md) | No | Yes | Yes |
| Retry analyst, scheduled tasks, test deploy, smoke and browser smoke, post-deploy validation, spend dashboards | No | Yes | Yes |
| HIPAA and HITRUST coding rules, PHI and secret guard | No | Yes | Yes |
| PR tracking and auto-fix, repo skills, MCP servers | Yes | Yes | Yes |
| Audit ledger retention | 90 days | Permanent | Permanent |
| AI providers | Anthropic | Anthropic, Bedrock | Also OpenAI, Vertex, fallback chains |
| Where Forge runs | Forgestus managed cloud | Forgestus managed cloud | Customer's AWS account (early access) |
| Support | Email | Slack | Direct access to the founder |

## Notes

- Anything about .NET Framework, migration or Parity Proof is a Business or Enterprise feature.
- Windows-based epics count as two epics against the monthly allowance.
- Running Forge inside your own AWS account is early access on Enterprise and is scoped with you.
- Bring your own AI key applies to every plan. See [Bring your own AI key](../get-started/byok.md).
- Some features are enabled per project even on a plan that includes them. Features marked <span class="badge badge-early">Early access</span> are scoped with you.
